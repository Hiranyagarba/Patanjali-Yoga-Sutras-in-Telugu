## మంగళాచరణం

**योगेन चित्तस्य पदेन वाचां ।**
>
**मलं शरीरस्य च वैद्यकेन ॥**
>
**योऽपाकरोत्तं प्रवरं मुनीनां ।**
>
**पतञ्जलिं प्राञ्जलिरानतोऽस्मि ॥**

### తాత్పర్యం

మనస్సులో ఉండే చంచలత్వాన్ని, కల్మషాలను తొలగించి మనశ్శాంతి కోసం యోగశాస్త్రాన్ని;

వాక్కులో దోషాలు లేకుండా స్పష్టత కోసం వ్యాకరణాన్ని;

మరియు శరీర ఆరోగ్య పరిపూర్ణత కోసం ఆయుర్వేద వైద్యశాస్త్రాన్ని,

మానవాళికి ప్రసాదించిన మునులలో అత్యంత శ్రేష్ఠుడైన పతంజలి మహర్షికి నేను చేతులు జోడించి నమస్కరిస్తున్నాను.
